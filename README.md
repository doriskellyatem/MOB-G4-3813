## How to run the app
1. Install Node.js (LTS version) and the Expo Go app on an Android phone.
2. Download or clone this repository, then open a terminal in the project folder.
3. Install the dependencies:
   npm install
4. Start the app:
   npx expo start
5. Scan the QR code shown in the terminal with the Expo Go app.
   The phone and the computer must be on the same Wi-Fi network.
